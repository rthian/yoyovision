# Sample dataset (synthetic)

Generated by `ml/scripts/generate_sample_dataset.py`. Every file under `videos/` is a short placeholder text marker, **not real video content** -- there is no real annotated 1A footage in this repository yet. Every annotation value (events, deductions, judge clicks, Freestyle Evaluation scores) is hand-authored to exercise the dataset schema end to end, not measured from real performance.

Regenerate with:

```bash
cd ml && python scripts/generate_sample_dataset.py
```

Validate with:

```bash
cd ml && python -m yoyovision_ml.dataset.cli validate sample_data/dataset_v1
```

`validation_report.txt` in this directory is a checked-in snapshot of that
command's output (plus `dataset stats`), regenerated whenever the dataset
schema, validators, or this sample data change. See
[`docs/annotation_handbook.md`](../../../docs/annotation_handbook.md) for
the annotator-facing guide this sample data is meant to illustrate.
